# 레드블랙트리

이진트리는 기본적인 데이터 구조이지만, 트리가 불균형해지면 성능이 저하될 수 있다. 레드 블랙 트리는 균형을 유지하기 위한 규칙 집합을 사용하여 트리의 초기 모양에 관계없이, `삽입`,`삭제 및 검색` 과 같은 작업에 대한 시간복잡도를 보장하는 규형잡힌 이진트리이다.

레드-블랙 트리는 각 노드에 추가 속성인 색상(빨간색 or 검은색)이 있는 자체 균형 이진 검색 트리이다. 주요한 목적은 삽입 및 삭제 중에 균형을 유지하여 효율적인 데이터 검색 및 조작을 보장한다.

## 레드블랙트리 규칙
1. 모든 노드는 블랙 또는 레드이다.
2. 루트 노드는 블랙이다.
3. 모든 리프(NULL) 노드는 블랙이다.
4. 모든 리프 노드에서 루트 노드까지 경로에 포함된 블랙 노드의 개수는 같다.
5. 레드 노드가 연속된 경로는 없다 (더블 레드 불가)
